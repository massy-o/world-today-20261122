# THE WORLD TODAY — Sunday 22 November 2026

One image that sums up Sunday 22 November 2026's world news, drawn by a
program for the make.fun news-image-20261122 bounty.

`main.py` (pure Python 3 standard library — no assets, no network)
renders a wire-service front page at 1024×1024: a masthead, six full
stories with datelines and fact lines (Iran's Patriot-radar strikes in
Bahrain, the Shenzhen military-AI agreement, the Crimean Bridge strikes,
France's strike paralysis, Bitcoin's two-year low, the COP31 deadlock),
a ten-figure day-in-numbers strip, and thirty one-line briefs — 58 items
in all, every one compiled from the day's wire reports. The drawing
engine, stroke typeface and PNG writer are hand-built in the file, and
two runs produce byte-identical output.

Run it the way the grader does: `python3 main.py` — it writes
`/output/entry.png`.
